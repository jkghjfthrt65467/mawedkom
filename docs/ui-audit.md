# تدقيق واجهة نوبو (قبل إعادة التصميم)

تاريخ: 17 أيلول 2026 — تدقيق بصري فقط، بدون تقييم منطق الحجز.

## الصفحات والمسارات الحالية

| السطح | المسارات |
|---|---|
| عام / زبون | `/` الرئيسية، `/salons` و`/salons/[city]`، `/c/[category]` و`/c/[category]/[city]`، `/salon/[slug]`، `/book/[slug]`، `/m/[token]`، بحث وفلاتر |
| حساب | `/login` `/register` `/forgot`، `/account` `/account/appointments` `/account/favorites` `/account/profile` |
| أعمال | `/business` `/business/signup`، `/business/manage` وأقسامها (نظرة عامة، تقويم، إحصائيات، مشروع، موظفون، عطل، ساعات، خدمات، ضبط، مواعيد)، `/staff`، `/whatsapp` |
| محتوى قانوني | `/about` `/faq` `/contact` `/blog` `/blog/[slug]` `/privacy` `/terms`، `not-found` |

لا توجد صفحة إشعارات مستقلة — الأقرب: التوست + مواعيدي.

## المشاكل البصرية

- هوية تسويقية بيج/عاج (`ivory` `#f8f3ec`، `sand` `#f3e8d8`) على كل السطوح، بما فيها لوحات المدير والموظف — ليست منصة حجز 2026.
- البرتقالي `#ff7802` موجود لكنه محاط بخلفيات فاتحة تُظهره كقالب حجز عام.
- لا يوجد وضع داكن، ولا شريط تنقّل سفلي للموبايل (قائمة همبرغر مكتظة).
- الرئيسية عمودية طويلة وليست bento؛ الإحصائيات مربعات متشابهة بلا تراتبية.
- الزجاج/الضباب شبه معدوم عدا `backdrop-blur` خفيف بالهيدر.
- التقويم: اليوم المحدد والعطلة والفراغ يتشاركون بيج/`palm-soft` — الحالات غير مميّزة.
- بطاقات الخدمة/الموظف صفوف حدود مسطّحة، بلا حالة selected واضحة.
- البحث أبيض على ظل أخضر قديم؛ الفلاتر chips صغيرة بدون sticky.
- معالج الحجز 5 شرائح أفقية تبدو طويلة؛ شاشة النجاح نص فقط بلا تأكيد بصري قصير.
- أيقونات مخلوطة (إيموجي تصنيفات، ☰، ★، نص) بلا مكتبة موحّدة.
- أهداف اللمس أحياناً أقل من 44px (chips التقويم/الفلاتر).

## اتجاه الإصلاح (هذا العمل)

كانفاس داكن فاخر + برتقالي أصلي، توكنات مشتركة، بريمِتفز (بطاقة، زر، إدخال، شريحة، تقويم)، شريط سفلي للموبايل، بدون حذف مسارات وبدون لمس منطق الأعمال.
