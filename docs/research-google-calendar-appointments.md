## 1. الفكرة الأساسية عند Google

**Appointment schedule** ليس حدثاً عادياً. هو قالب توفر يولّد **صفحة حجز عامة** (`booking page`) بحيث يختار الزائر وقتاً فارغاً دون أن يرى تفاصيل يومك.

الفرق عن مشاركة التقويم كاملًا: المشاركة تكشف العناوين والتفاصيل؛ جدول المواعيد يعرض **فقط الفترات القابلة للحجز**. الأوقات المشغولة (Busy) تُحجب تلقائياً من الصفحة.

بعد الحجز: يظهر الموعد في تقويم المنظم + دعوة/تأكيد للضيف. لا إدخال يدوي.

متاح لحساب Google شخصي أو Workspace من **الحاسوب** (إنشاء الجدول ليس من تطبيق الموبايل). ميزات متقدمة (صفحات متعددة، تذكيرات، تحقق بريد، دفع Stripe، حدود يومية…) تتطلب اشتراك Workspace/Google One مؤهّل.

## 2. مفاهيم المالك / المنظم (Owner)

| المفهوم | سلوك Google | ملاحظة لنوبو |
|---|---|---|
| عنوان الجدول | يظهر في صفحة الحجز وعلى التقويم | اسم الخدمة / نوع الموعد |
| المدة (duration) | 15–60 د أو مخصص | مدة الخدمة في نوبو (`durationMin`) |
| نوافذ التوفر | أيام/ساعات أسبوعية؛ «غير متاح طوال اليوم»؛ فترة إضافية لنفس اليوم؛ نسخ لكل الأيام | ساعات العمل + عطل أسبوعية |
| المنطقة الزمنية | تُضبط على الجدول | العراق: `Asia/Baghdad` (بدون DST) |
| نافذة الجدولة | أقصى حجز مسبقاً + حد أدنى للإشعار (lead time) | غير مطلوب في هذه المرحلة |
| توفر معدَّل | تاريخ محدد أطول/أقصر أو مغلق بالكامل (عيد) | `holidayDates[]` + ساعات اليوم |
| فاصل (buffer) | دقائق قبل/بعد الموعد حتى لا تُح ramى الجلسات | المدة نفسها تُشغل الكرسي؛ لا فاصل إضافي افتراضي |
| حد الحجوزات/يوم | سقف يومي اختياري | غير منفَّذ الآن |
| تقاويم التعارض | «Check calendars for availability» — أحداث Busy تُخفي الساعة | حجوزات الموظف المؤكدة/المعلّقة تُغلق الفترة |
| مضيفون مشاركون (co-hosts) | يُضافون للموعد؛ **لا يُفحص تقويمهم إلا إذا فعّلت الفحص** | كل موظف = تقويم مورد مستقل يُفحص دائماً |
| صفحة الحجز | اسم، صورة، موقع/Meet/هاتف/لاحقاً، وصف، نموذج (اسم، بريد، حقول إضافية)، تحقق بريد ضد السبام | معالج نوبو العام `/book/[slug]` (اسم + هاتف عراقي) |
| التأكيد والتذكير | حتى 5 رسائل بريد؛ النص غير قابل للتحرير | واتساب: إنشاء + تذكير قبل ساعتين |
| الدفع/سياسة إلغاء | Stripe اختياري | الدفع عند المحل — بلا تسعير اشتراك في نوبو |
| ربط ومشاركة | رابط صفحة الحجز (إيميل، موقع، ملف) | رابط `/book/rafidain-barber` |

إنشاء الجدول (ملخص المقال + مساعدة Google):

1. تقويم Google → إنشاء → **Appointment schedule**.
2. عنوان، مدة، أيام/ساعات التوفر (متكرر أو نوافذ محددة). Google يحجب المحجوز مسبقاً.
3. ضبط: lead time، buffers، حد يومي، تحقق بريد، وصف، نوع اللقاء، حقول النموذج.
4. حفظ → نسخ رابط صفحة الحجز ومشاركته.

ما يراه الزائر: اسمك، نوع الموعد، الفراغات فقط. يختار ساعة → اسم وبريد → تأكيد للطرفين.

## 3. عروض التقويم (Calendar views)

تقويم Google التشغيلي (ليس صفحة الحجز):

| العرض | الاستخدام |
|---|---|
| يوم | خط زمني بالساعات؛ مناسب للموبايل والتشغيل اللحظي |
| أسبوع | شبكة 7 أيام؛ العمل اليومي للمنظم |
| شهر | نظرة كثافة؛ اختياري |
| جدول/أجندة | قائمة |

جدول المواعيد يظهر ككتلة توفر على الشبكة. الحجوزات أحداث عادية يمكن فتحها. الوقت الحالي يُعلَّم بخط.

نوبو: أسبوع + يوم أساسيان، شهر مبسّط. الأسبوع العراقي يبدأ **السبت**.

## 4. حجب المشغول ومنع التعارض

Google يخفي من صفحة الحجز أي فترة:

- داخلها حجز على هذا الجدول، أو
- حدث Busy على التقاويم المحددة (بما فيها بعض ردود Maybe/Yes)، أو
- خارج نافذة التوفر / استثناء التاريخ / بعد استنفاذ الحد اليومي / داخل الـ buffer / أقرب من lead time.

حذف **الجدول** لا يحذف الحجوزات السابقة؛ الروابط تتوقف. إلغاء **موعد محجوز** يزيل الحدث، يرسل إيميل إلغاء، ويُعيد الساعة للصفحة.

إعادة الجدولة: من الحدث أو من رابط التأكيد (حسب المنتج). الإيميل المُحوَّل قد يسمح للغير بالإلغاء — ثغرة خصوصية عند Google؛ نوبو يستخدم رمز إدارة فردي `/m/[token]`.

## 5. الموظفون مقابل المالك عند Google وRandevu Nasıl

**Google** مصمم لشخص واحد (+ مضيفين). لا «بوابة موظف صالون». التعدد = تقاويم/حسابات متعددة أو co-hosts مع فحص توفر صريح.

**Randevu Nasıl Business** (من البحث السابق):

- المالك: تقويم موحّد لليوم، أعمدة متعددة للموظفين، فلتر موظف/حالة، موافقة يدوية بلمسة، إيقاف استقبال، نقل موعد.
- الموظف: تقويمه فقط + صلاحيات (هاتف الزبون، الأرباح…) يضبطها المالك.
- إذن/عطلة الموظف تُغلق تقويمه؛ الباقي يبقى مفتوحاً.
- AUTO يثبت فوراً؛ MANUAL يبقى معلّقاً حتى موافقة المالك.

**نوبو في هذه الجولة**

| | صاحب المشروع | الموظف |
|---|---|---|
| المسار | `/business/manage/calendar` (PIN 1234) | `/staff` أو `/business/staff` (PIN + اختيار الاسم) |
| الرؤية | كل الحجوزات، ملوّنة حسب الموظف | مواعيده فقط |
| إنشاء | نقر فراغ: حضور/هاتف | نقر فراغ على جدوله |
| الحالة | تأكيد / إلغاء / إعادة جدولة / مكتمل / لم يحضر | عرض + إلغاء + مكتمل / لم يحضر |
| العطل والإيقاف | يضبطها؛ يراها على الشبكة | يراها محجوبة؛ لا يرى تقويم غيره |

## 6. ما بُني في نوبو (مقابل Google)

| Google | نوبو |
|---|---|
| Appointment schedule + booking page | ساعات العمل + خدمات بمدد + `/book/[slug]` |
| Busy blocking | تعارض المدة لنفس الموظف (مؤكد/معلّق/مكتمل) على القرص `.data/bookings.json` |
| Adjusted availability / عطل | `weeklyOffDays` + `holidayDates` + يوم مغلق في الساعات |
| Buffer | طول الخدمة يشغل الفترة |
| Co-host calendars | موظف = مورد؛ المالك يرى الكل |
| تأكيد بريد | واتساب للزبون + صاحب المشروع (بما فيها حجوزات التقويم) |
| إلغاء يعيد الساعة | `cancelled` يحرّر الفترة |
| Day/Week | يوم + أسبوع (+ شهر اختياري) |
| يدوي/تلقائي | `approvalMode` AUTO/MANUAL — المعلّق شكل مختلف على التقويم؛ إنشاء المالك/الموظف يُثبَّت فوراً |
| منطقة زمنية | `Asia/Baghdad` |

خارج النطاق الآن (موجودة عند Google): lead time، سقف يومي، Stripe، تحقق بريد، Google Meet، سحب الأحداث بمكتبة ثقيلة (التعديل من نافذة الوقت).
