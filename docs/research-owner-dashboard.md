### 2.2 حقول يحرّرها المدير (تظهر في الملف العام)

من `/salon/rambey-randevu` + موقع القالب + شاشات الملف:

| الحقل | أين يظهر للزبون | ملاحظة |
|---|---|---|
| اسم المشروع | H1 الملف + البطاقة + الحجز | إلزامي عند الإنشاء |
| وصف/نبذة | قسم عن المحل + SEO | نص حر |
| صورة/شعار + معرض | هيرو ومعرض API `uploads/{logo\|hero\|gallery}` | رفع من التطبيق (منذ 1.6.3 شعار، 2.2.3 معرض) |
| الفئة والمدينة والحي | فتات خبز + البطاقة | عند التسجيل: قطاع + مدينة/حي |
| العنوان النصي | تبويب الموقع | مثال: Adnankahveci mah. … Beylikdüzü |
| GPS / خريطة | OSM embed في الملف | الزبون يرى النقطة لا يحرّرها |
| هاتف المشروع | رابط اتصال ظاهر | مثال 05344528834 |
| ساعات العمل | Schema + ملف/موقع القالب | أيام مفتوحة + مدى ساعات؛ أيام مغلقة لا تُعرض كمواعيد |
| الخدمات | قائمة: اسم، مدة دقائق، سعر، زر احجز | سعر ₺1 = placeholder من المدير |
| الموظفون | تبويب الفريق: اسم + صورة `uploads/staff/` | رفع صورة موظف منذ 1.5.3؛ نبذة/تخصص في الملف التشغيلي |
| رابط الحجز | Instagram / WhatsApp / Google | يُولَّد بعد الخدمات+الموظفين+الساعات |
| وضع الموافقة | سلوك الحجز لا نص ظاهر | AUTO يثبت فوراً؛ MANUAL يبقى معلّقاً |
| تقييمات | تبويب + رد «İşletme yanıtı» | المدير يرد من التطبيق |

لا تحصيل من الزبون داخل المنصة. الدفع عند الصالون.

## 5. سلوك العطل وإيقاف الموظف (للتنفيذ)

### 5.1 عطلة المحل

طبقتان منفصلتان في الأصل:

1. **أيام أسبوعية مغلقة** (مثال: الأحد، أو الجمعة) — تُعرَّف مع ساعات العمل. الزبون لا يرى slots.
2. **تواريخ محددة** (عيد، إجازة سنوية، صيانة) — تُغلق ذلك اليوم لكل الموظفين.

الساعات اليومية (فتح/إغلاق) تُولّد الفترات فقط في الأيام غير المغلقة.

### 5.2 إيقاف / إذن الموظف

- إذن أو مرض أو «غير متاح»: تقويم ذلك الشخص يُغلق؛ الزبون لا يحجز عليه.
- باقي الفريق يبقى قابلاً للحجز («أي متاح» يتجاهل المتوقف).
- إيقاف الاستقبال على مستوى المشروع: الرابط يرفض حجوزات جديدة بالكامل.

نوبو يوحّد هذا بثلاثة ضوابط واضحة:

- `weeklyOffDays[]` — عطل أسبوعية  
- `holidayDates[]` — تواريخ إغلاق  
- `staff.bookingPaused` — إيقاف حجوزات موظف  
- `bookingIntakePaused` — إيقاف المشروع كله

## 6. تدفق إعداد صاحب العمل (كما يُعلَن)

1. تحميل التطبيق وإنشاء حساب (هاتف).  
2. اسم المشروع، القطاع، هاتف، مدينة/حي، عنوان.  
3. خدمات (اسم، مدة، سعر، من يقدّمها).  
4. موظفون (اسم، صورة، خدمات، ساعات؛ يمكن أن يكون المدير أول موظف).  
5. ساعات العمل + أيام مغلقة.  
6. وضع الموافقة + واتساب تذكير + رابط الحجز.  
7. مشاركة الرابط في إنستغرام / واتساب / Google.  
8. التشغيل اليومي: تقويم، موافقة يدوية، رد تقييمات، إيقاف عند الحاجة.

لا اشتراك في تكييف نوبو (المنصة مجانية بلا خطط).

## 7. IA لوحة مدير نوبو (تطابق كل ضبط مفيد)

الجمهور: «مدير المشروع» — صاحب صالون/عيادة.  
المسار: `/business/manage` و`/business/manage/[section]`.  
الدخول: رمز محلي (PIN تجريبي `1234`) في `localStorage`.  
الرابط في الترويسة/الحساب/صفحة الأعمال: «لوحة المدير».  
المشروع التجريبي المُدار: `rafidain-barber` — القائمة والملف والحجز يقرأون النسخة المعدّلة.

```
/business/manage                نظرة عامة + رابط الحجز + حالة الإيقاف
/business/manage/project        المشروع: اسم، وصف، صورة، هاتف، GPS
/business/manage/staff          الموظفون: CRUD + صورة + نبذة + إيقاف حجوزات
/business/manage/holidays       عطل أسبوعية + تواريخ إغلاق
/business/manage/hours          ساعات كل يوم
/business/manage/services       الخدمات: اسم، مدة، سعر، ربط موظفين
/business/manage/settings       موافقة AUTO/MANUAL، واتساب، إيقاف المشروع
/business/manage/bookings       مواعيد هذا المشروع
```

حقول إلزامية في «المشروع» كما طُلبت + ما يلزم ليكون الضبط كاملاً:

1. اسم، وصف، صورة (رفع أو رابط)، عنوان GPS (lat/lng + خريطة/بحث)، هاتف.  
2. موظفون كاملون: اسم، صورة، وصف/نبذة، إضافة/تعديل/حذف.  
3. إيقاف الحجوزات لكل موظف → المعالج يخفي/يعطّل.  
4. عطل أسبوعية + تواريخ → التقويم يمنع اليوم + حالة فارغة واضحة.  
5. ساعات، خدمات، موافقة، رابط واتساب، إيقاف استقبال المشروع — كما في الأصل.

التخزين: `lib/store.ts` فوق بيانات `lib/data.ts`. الهوية: برتقالي `#ff7802`، عربي RTL، بلا أسعار/خطط.
