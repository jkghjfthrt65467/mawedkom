# موعدكم — تطبيق المدير (أندرويد)

يرسل إشعارات واتساب من هاتف صاحب المشروع بعد ما الموقع يشتغل على Render. إذا الجهاز بلا نت، الرسائل تبقى بالطابور وتنرسل أول ما يرجع الاتصال.

```bash
cd apps/owner-android
npm install
npx expo start
```

بعد الفتح: رابط موقع موعدكم على Render، رمز المشروع، ورمز المدير `1234`. لازم واتساب يكون مثبت على نفس الهاتف.
